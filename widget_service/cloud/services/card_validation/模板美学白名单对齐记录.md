# 模板设计与美学校验白名单对齐

2026-09-10 按用户指定，以 `template_generation` 的正式模板、主题和转换器设计值为标准。
本记录补充来源与证据，正式行为以 `docs/云侧方案设计.md` 的“校验与重试”为准。

完整的前后方案分析与实施过程见[美学校验向模板标准对齐过程复盘](../../../../docs/美学校验向模板标准对齐过程复盘.md)。

## 来源与范围

- `template_generation/resources/source/providers/*/templates/*.cardtpl`：业务模板、布局模板、操作模板。
- `template_generation/resources/source/themes/*/theme.json`：14 套正式主题的颜色、渐变、表面与圆角。
- `template_generation/resources/source/themes/base/theme-base.json`：安全边距、组件间距和尺寸密度预算。
- `template_generation/engine/tersel_converter.py`：通用文字与按钮设计，包括 14/16vp 按钮圆角。
- `template_generation/engine/cardplan/preview_dataset.py`：107 个业务模板的实际展开结果。

没有修改以上生成源或模板。没有依赖 `template_root` 标记来放行单项规则；107 个预览直接执行完整
质量校验器，绕过公共管线的豁免分流来检查真实兼容性。所有模板变体的固定字号、字重、间距还会从
解析后的正式模板定义逐项核对，包含不在业务预览列表里的操作和布局模板。

## 对齐明细

| 类别 | 原差异 | 对齐处理 |
| --- | --- | --- |
| 颜色 | 正式模板与主题的 ARGB 和 alpha 已在原规则范围 | 不扩大颜色格式、alpha 或 opacity 白名单；14 套主题测试确认兼容 |
| 渐变 | 正式主题的 direction、颜色 stops、透明渐变已受支持 | 保留方向、色标合法性、顺序和 0～1 覆盖检查；不引入渐变通用豁免 |
| 圆角 | 通用小按钮使用 14/16，图标操作使用 15，胶囊使用 18 | 按钮最低 14；允许 14、15、16、18、20 共用模板圆角体系；根继续 18/20 |
| 字体 | 模板存在 8、9.14、11、13.71、24、28、30、34、38、56 | 纳入字号表；原有合法档位继续保留；标题允许 12、14、16、18、20 |
| 字号自适应 | 模板只写 minFontSize；旧校验要求 min/max 成对 | 没有 max 时用 fontSize 为上界，仍拒绝倒置或无法确认的范围 |
| 安全边距 | 模板根外壳 padding 为 0，内容层承担安全区 | 检查内容层 12vp；支持零 padding 根 Stack 的唯一铺满内容容器，保留模板和融球前景识别，未分层结构仍检查根；普通档位不能替代安全边距 |
| 内外间距 | 日程微调、耳机分区使用非旧档位 | padding、margin、itemMargin/space 分表；负值 -2 仅登记到 margin |
| 区域组织 | 加权子项的 matchParent 被当作完整父宽重复累加 | 固定尺寸与间距先扣除，再按 layoutWeight 分配；子树检查使用分配后的宽高 |
| 信息密度 | theme-base 规定 2x2 最多两操作、2x4 最多一操作 | 同步显式操作上限；根容器隐式入口不计数，保留多主操作提示；大数字上限不变 |
| 文字对比度 | 固定模板配色被通用 3:1 / 4.5:1 阈值报告 | 51 个精确前景与合成背景组合单独登记；未登记组合仍走原阈值 |

当前间距表：

- 组件间距：0、1、2、3、4、6、8、10、12、14、16。
- padding：0、2、4、6、7、8、10、11、12、14、16、34。
- margin：-2、0、2、3、4、5、6、8、10、12、13、14、16。

## 精确配色白名单

`cloud/data/validator_rules/config/template_contrast.json` 由
`cloud/services/card_validation/sync_template_contrast_allowlist.py` 生成，每条组合保留正式主题路径或模板 ID 来源。
运行时只读取已生成配置，不加载模板生成器。

组合同时匹配前景色和完整的合成背景样本集合，背景 RGB 归一化至小数点后 9 位。
不同组件 ID 可以使用同一标准配色；仅名字相同、颜色接近、前景一致但背景不同均不自动放行。
渐变样本集合也必须整体匹配，不能只命中其中一个亮端或暗端。结构错误仍由渐变校验器报告。

该白名单是用户认可的设计例外，不表示低于通用阈值的组合已经达到可访问性标准，也不是端侧像素测量。
融球专项的结构、局部确定背景对比度与渲染复核规则不变；公共根双标记跳过、单融球仅专项的分流不变。

在 `widget_service` 下运行：

```text
python cloud/services/card_validation/sync_template_contrast_allowlist.py
python cloud/services/card_validation/sync_template_contrast_allowlist.py --check
python -m pytest tests/test_template_aesthetic_alignment.py -q
python tests/run_aesthetic_rule_fixtures.py generate --local-config-default
python tests/run_aesthetic_rule_fixtures.py check --local-config-default
```

缺少本地华山开关配置时，前三项也应在现有 `local_configuration(True)` 测试上下文中运行。
该上下文只补齐测试进程缺失值，不修改磁盘配置。正常配置完整的环境直接执行即可。

## 测试证据与迁移

对齐前 107 个预览共产生 404 条质量诊断：对比度 240、字号 97、间距 52、横版闭合 15。
对齐后直接执行全部质量校验器为零诊断；14 套正式主题的颜色、渐变、表面组合也直接校验。
反例覆盖非法负 padding/间距、未登记外边距、错误字号范围、加权布局的后代溢出和最小尺寸越界、
过小圆角及非标准低对比度配色。

旧美学反例中的 3vp 外边距、16vp 按钮圆角、14vp 标题已变成合法值，已修复测试生成器并重新生成
716 个数据文件，使用 9vp 外边距、12vp 按钮圆角和 24vp 标题等仍然不合规的负例。
操作数量负例改为 2x4 两操作触发超限，2x2 两操作只触发多主操作提示。
测试生成源、正常对照和单点差异仍需同时验证，不能只更新预期诊断或手工修改生成文件。

本次相关回归 1221 项通过（包含模板编译公开入口的 4 项回归）；配色白名单和美学单点数据的
生成一致性检查均通过。
